# ATELIER 24 INDIA — Contemporary Fashion E-Commerce Website & Checkout Simulator

A clean, responsive, fully interactive mock fashion e-commerce store regionalized for **India**, featuring Indian Rupee (`₹`) pricing, lively high-fashion model photography, UPI / RuPay / NetBanking / COD checkout, GST tax calculations, and a dynamic promo code engine.

---

## 🌟 Indian Regionalization Highlights

1. **Currency & Pricing**:
   - All prices formatted in **Indian Rupees (₹)**: e.g. `₹4,999`, `₹3,899`, `₹1,999`.
   - Free shipping threshold at **₹1,999** with dynamic progress bar.
   - Standard delivery: **₹149**; Priority Express: **₹299**.
   - **GST (Goods & Services Tax)** calculated accurately at 12%.
2. **Alive, High-Fashion Model Imagery**:
   - High-energy, editorial photography of models in motion, street style, candid chic poses, and vibrant lighting.
   - Badges: *"Trending in Mumbai"*, *"Bestseller"*, *"Pure Mulberry Silk"*, *"New Arrival"*.
3. **Indian Payment Methods**:
   - **UPI / QR**: Google Pay, PhonePe, Paytm, BHIM with instant VPA verification.
   - **RuPay / Visa / Mastercard**: Live 3D interactive card preview with RuPay branding.
   - **NetBanking**: Major Indian banks (HDFC, ICICI, SBI, Axis).
   - **Cash on Delivery (COD)**: Doorstep cash or UPI QR payment option.
4. **Promo Codes Engine (India Region)**:
   - `FASHION20`: 20% discount on order subtotal.
   - `SAVE10`: Flat **₹500 discount** applied.
   - `FREESHIP`: 100% Free Shipping across India (saves ₹149).
   - Quick one-click pill buttons to test any promo code instantly.
5. **Indian Delivery Details**:
   - Sample address: Ananya Sharma, Indiranagar, Bengaluru, Karnataka (560038).
   - Mock tracking via BlueDart / Delhivery Air Express.
   - GST invoice receipt with printable format.
